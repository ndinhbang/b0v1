```bash
nginx -v # Show NGINX version information
nginx -V # Show NGINX version and configure options
nginx -t # Test NGINX configuration for syntax errors
nginx -s <signal> # Send a signal to the NGINX master process (e.g., stop, quit, reload, reopen)
nginx -c <file> # Specify an alternative configuration file
nginx -e <file> # Specify an alternative error log file
```
